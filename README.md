# LLM and RAG Engineering — From Scratch to Production

A hands-on implementation of LLM concepts and RAG pipelines
built from scratch without frameworks.

## What's covered
- OpenAI API fundamentals
- Tokenization with tiktoken
- Transformer attention visualization
- Prompt engineering techniques
- RAG pipeline from scratch
- pgvector integration with PostgreSQL
- HNSW indexing for production scale

## Tech Stack
Python · OpenAI API · PostgreSQL · pgvector · Docker · tiktoken · psycopg2

## Modules
- module1_llm_foundations — LLM basics, tokenization, transformers, prompting
- module2_rag — RAG pipeline, embeddings, pgvector integration
